## 3. 피처 엔지니어링 및 휴장일·비수기 분리

1. **휴장일 및 비수기 완전 제외**:
   - 일요일 정기 휴장일, 양력 법정 공휴일, 설날·추석 연휴(`D-1 ~ D+2`), 일 거래량 100kg 미만일 제거
   - 품종별 52주차 평균 출하량 기반 비수기 자동 판별(피크 대비 1.5% 미만 또는 연간 비중 0.25% 미만 주차) 후 학습·예측·시각화에서 자동 분리
2. **입력 피처 구성 (거래량 33개 / 가격 33개 + 시계열 래그 8개)**:
   - **정적·계절 피처**: `(품종 × 거래단위)` 기준 일평균 물량·단가, 단위중량, 월별 계절성 기대치, 연중/반년/요일 삼각주기(`sin/cos`), 연도 추세
   - **명절 피처**: 설날·추석 대목(`D-18~D-1` Pre-Surge) 및 직후 조정(`D+1~D+12` Post-Dip) 가우시안 곡선, 품종·단위별 명절 민감도
   - **제주 산지 기상 피처 (`forecast.csv`, 1주 전 기준)**: 1주 전 평균기온, 평년대비 기온편차, 누적 강수계속시간, 일조시간, 최심신적설, 강우 레짐(`건조·청명 / 보통강우 / 장시간강우`)별 품종 민감도
   - **단기·예년 변화량 래그**: 영업일 기준 $t-1, t-2, t-3, t-7, t-14, t-30$ 래그, 1주 전 대비 변화량($\Delta 1w$), 7일/14일 이동평균, 예년(2021~2025) 동시점 물량·단가 및 주간 변화량($\Delta\text{예년}$), YoY 편차, 전일 특등급 비중

## 4. 모델 아키텍처 및 6-Fold 분기별 랜덤 2주 검증(Folding) 설계

### 4.1 학습 기간 및 6-Fold 분기별 랜덤 2주 폴딩 (`assign_quarterly_2week_folds`)
- **학습 데이터 범위**: **`2021-01-02 ~ 2026-11-30`** (보유 최신 데이터인 `2026년 11월 11일`까지 전체 포함; 기존 `2021~2024/2025` 학습 대비 최신 2026년 시세·수급 레짐 반영)
- **검증 분할 방식 (Randomized Quarterly 2-Week 6-Fold CV, `seed=42`)**:
  1. 전체 기간을 **3개월(1분기: Q1~Q4)** 단위 블록으로 분할
  2. 각 3개월 블록(약 90일)을 6개의 연속 **약 2주(15일)** 구간으로 나눈 뒤, **분기마다 독립 랜덤 셔플(`rng.permutation(6)`)**로 6개 Fold에 배정
  3. 각 Fold $k \in \{1..6\}$ 학습 시: 모든 3개월 블록에서 **서로 다른 랜덤 2주 구간(~16.7%)**을 검증셋으로, 나머지(~83.3%)를 학습셋으로 사용 (특정 월초/월말 편향 제거 + 연속 2주 블록으로 시계열 단기 누수 방지)
  4. **과거 구간(`2021-01 ~ 2026-11`)**: 각 날짜를 검증셋으로 보유했던 Fold 모델의 **100% Out-of-Fold(OOF) 검증 예측치**로 평가
  5. **미래 구간(`2026-11-12 ~ 2026-12-31` / `2027-02-20`)**: 6개 Fold 모델의 예측(P10, P50, P90)을 **앙상블 평균**하여 분산 최소화 (날짜별 배치 추론 + Cython 트리/Booster 직접 호출로 고속화)

### 4.2 4대 예측 모델 명세 (공통 P10 / P50 / P90 분위수 예측)

| 모델 | 구현 파일 | 타깃 변환 (거래량 / 가격) | 손실함수 및 핵심 구조 |
| :--- | :--- | :--- | :--- |
| **TFT** | `tft.ipynb`, `build_market_predictions.py` | `log1p(ton)` / Z-score | PyTorch `TFTQuantileNet` (VSN + 3×GRN + Pinball Loss, AdamW + CosineAnnealing) |
| **XGBoost** | `xgboost.ipynb`, `build_market_predictions.py` | `log1p(ton)` / Z-score | `reg:quantileerror` ($\alpha \in \{0.1, 0.5, 0.9\}$), `tree_method='hist'`, `max_depth=6~7` |
| **LightGBM** | `lightgbm.ipynb`, `build_market_predictions.py` | `log1p(ton)` / Z-score | `objective='quantile'`, `num_leaves=63~75`, `max_depth=9~10` |
| **Random Forest** | `random_forest.ipynb`, `build_market_predictions.py` | `log1p(ton)` / Z-score | Quantile Regression Forest (`max_depth=18`, `min_samples_leaf=3`, 트리 분포 기반 P10/P50/P90) |

  2. **TFT의 비약적 성능 향상 (전 부문 1위)**: 6-Fold 랜덤 2주 앙상블로 딥러닝 분산이 크게 감소하며 실제 미래 블라인드 검증에서 **전국 가격 90.49%, 전국 거래량 94.94%(MAE 20.79톤), 5대 시장 가격 78.33%, 5대 시장 거래량 82.69%**로 압도적 1위 달성.

## 6. Streamlit 대시보드 (`app.py`) 기능 및 개선 내역

- **조회 조건**: ① 도매시장 선택(`전체시장` + 5대 도매시장) $\rightarrow$ ② 품종 선택(4대 핵심 품종) $\rightarrow$ ③ 거래단위 선택(상위 5개) $\rightarrow$ ④ 기준 날짜 선택(`2021-01-02 ~ 2026-12-31`)
- **시각화 구성**:
  1. 선택일 포함 주간(월~토) KPI 요약 카드 (실제 결과 · 예년 2021~2025 평균 · 모델 예상치)
  2. 주간 거래량 및 가격 비교 그래프 (실제 vs 예년 vs 예측 + P10~P90 불확실성 구간)
  3. 4개 모델(`TFT`, `XGBoost`, `LightGBM`, `RandomForest`) 2×2 개별 상세 이중축(거래량 막대 + 가격 선) 비교 그래프
  4. 모델별 가격·거래량 정확도(`100 - MAPE`, `100 - WMAPE`, `R²`) 비교 그래프 및 주간 상세 비교표(CSV 다운로드 지원)
  5. 계절적 비수기 선택 시 예측 그래프 자동 숨김 및 출하기 안내 카드 표시
- **주요 수정 및 안정화 내역**:
  - `get_pkl_path()` 경로 자동 탐색 함수 도입으로 `str.exists()` 오류(`AttributeError`) 해결 및 실행 위치(`jhd/` 또는 루트) 무관 정상 로드
  - **그래프 내부 전체 영문화 + `DejaVu Sans` 폰트 고정**: Matplotlib으로 렌더링되는 3개 그래프의 제목·축·범례·요일/날짜 눈금·주석을 모두 영어로 통일하여 OS/Docker 환경에서의 한글 깨짐 문제 완벽 해결 (대시보드 본문 UI·표는 한글 유지)
